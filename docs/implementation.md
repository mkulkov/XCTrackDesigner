2026-10-10. Доступны импорт и экспорт копий backup/pages профиля 0.9.12.6 / 91260, создание конфигурации, независимые страницы/ориентации, структурные команды страниц и виджетов, шаблоны из импорта, оформление, drag/resize, keyboard commands, undo/redo и сценарии показаний. Онлайн-подложки добавлены по последнему запросу пользователя; описание и ограничения ниже.

## Модель совместимости

`web/src/xcfg.ts` сохраняет исходные UTF-8 bytes, текст и RFC6901 token spans. Сканер отвергает duplicate keys (включая escaped aliases), неверный JSON, глубину >64, >100000 nodes, >5 MiB, >100 pages в ориентации, >5000 widgets и некорректные normalized bounds. JSON.parse используется только для UI projection. Неизвестные числа могут превосходить точность JS: их исходные lexemes сохраняются, они не используются как редактируемые значения.

No-op download отдаёт исходные bytes, включая BOM, CRLF и пробелы. Применение координат заменяет только токены изменённых X1/Y1/X2/Y2. Затем документ повторно валидируется; preferences/info/unknown settings не сериализуются и не исправляются. Unknown CLASS сохраняется. Версия/тип вне профиля доступны read-only с экспортом исходного документа. Исходный файл никогда не перезаписывается.

Selection использует внутренние устойчивые widgetIds; каждая команда хранит immutable snapshot. Duplicate/delete доступны через token splice API. Перед добавлением reordering и операций со страницами нужно расширить этот API и identity страниц. Raw tree из архитектуры в этом прототипе заменён текстом со spans как источником истины; это усиливает lexical preservation. Новые поля и операции со страницами требуют расширения patch API.

## Геометрия и визуальные ограничения

Grid count/coordinate mapping перенесён из `ui/i0.java` и `d0-raw.java`: cells = round(pixels / max(8, 0.11952191 * dpi)); normalized → floor((bound*cells+5000)/10000); pixel = round(cell*pixels/cells). При collapsed range метод d0.E разворачивает ось целиком. Вход уже ограничен 0…10000, поэтому native out-of-range shifting не нужен.

Viewport фиксирован на исследованном Android: portrait 1080×2400, landscape 2400×1080, 420 dpi. SVG масштабируется для интерфейса; это не native-resolution screenshot для pixel diff. Виджеты идут в исходном порядке; selection overlay отдельно. Explicit _bg использует native integer alpha; absent defaults пока не воспроизведены. Для трёх сложных map/thermal widgets рисуется условная светлая/тёмная подложка, чтобы прозрачные текстовые widgets оставались видимыми. Это схема карты, не native renderer.

WSpeed, WVerticalSpeed, WAMSL, WAirTime имеют приближённые значения, подписи и системный browser font. Распознавание по полному CLASS. Title/unit flags учитываются, но font metrics, outlines, dynamic colors, title position, labels, locale и no-data states ещё не перенесены. Неизвестные единицы отображаются схемой; импортированные строки/URL/HTML не исполняются. Placeholder не означает поддержку native алгоритма.

Ползунки ручных показаний используют km/h, m/s, m и seconds и не затрагивают документ. Это начальный preview input, не физическая flight simulation и не deterministic replay.

## Редактирование на холсте

По запросу пользователя приоритет перенесён с полного совпадения шрифтов на редактор. Доступны перемещение мышью/Pointer Events, четыре угловых маркера размера и отключаемая привязка перемещения к шагу native grid при 420 dpi. Верхний виджет выбирается по исходному порядку слоёв; перекрытые виджеты доступны через список слоёв. Во время жеста показывается рамка будущего положения; содержимое обновляется после отпускания указателя.

Координаты вычисляются через обратную SVG screen matrix, поэтому масштаб предпросмотра не влияет на движение. Перемещение сохраняет размеры и ограничивается страницей; resize не пересекает противоположный угол, минимальный размер — одна ячейка. Дельта привязана к шагу сетки относительно исходной позиции, поэтому существующие несеточные координаты не исправляются автоматически. Один завершённый жест создаёт одну команду истории. Escape, pointercancel и потеря захвата отменяют черновик; нулевой жест не меняет исходные байты. Read-only документы можно выбирать, но нельзя двигать или растягивать.

Структурные операции (добавление/удаление/дублирование страниц и виджетов) остаются следующим этапом и требуют patch API для массивов и устойчивых идентификаторов. Полное визуальное совпадение шрифтов не является условием продолжения редактора.


Проверки редактора: npm run check — 29 Vitest, 6 Python, typecheck/lint/format и build прошли. Playwright с приватной копией sample — 6 сценариев прошли (включая drag/resize/Escape/undo и byte-preserving sample export); отдельный opt-in эксперимент шрифтов пропущен. Проверки холста выполнялись в Chromium, новый импорт изменённых жестом координат на Android в этой итерации не выполнялся.

## Операции над списком виджетов

Добавлены дублирование и удаление выбранного виджета. Копия вставляется сразу после оригинала и изначально перекрывает его; выбранной становится копия. Её можно переместить холстом или координатами. Неизвестные CLASS также копируются с полными настройками. Удаление выбирает соседний оставшийся виджет; пустая страница разрешена, пока в конфигурации есть хотя бы один виджет. Последний виджет конфигурации защищён от удаления. Каждая операция занимает один шаг undo/redo; редактирование после undo очищает ветку redo.

`editWidgetList` вставляет исходный JSON token или вырезает token с соседним разделителем массива. Остальные байты остаются исходными, включая BOM, CRLF, неизвестные поля и числовые лексемы. После операции scanner заново вычисляет spans. Внутренние widgetIds хранятся рядом с Document, сохраняются при координатных правках и в истории; новый ID получает только копия. Выделение использует ID, а не смещающийся индекс массива. ID не добавляются в исходный JSON и не экспортируются. Если выбранного ID нет в текущем snapshot, показывается первый доступный виджет.

На следующем checkpoint реализованы каталог новых виджетов и структурные операции со страницами; native Android import/export структурно изменённого документа также проверен (см. следующий раздел).


Проверки структурных команд: npm run check — 34 Vitest, 6 Python, typecheck/lint/format и build прошли; после финального UI изменения выполнен повторный build. Playwright с приватным sample: 8 сценариев прошли, 1 эксперимент шрифтов пропущен. Проверены duplicate/delete, неизменность unrelated настроек и ориентации, undo/redo и очистка redo-ветки, повторный импорт экспорта, пустая страница и read-only ограничения. Android import нового структурного экспорта в этой итерации не выполнялся.

## Основной редактор и сценарии

Реализованы создание нового pages-only документа, каталог WSpeed/WVerticalSpeed/WAMSL/WAirTime, добавление из любого исходного widget template (включая неизвестные CLASS), создание/копирование/удаление/порядок страниц и слоёв. Новая страница использует WPXCAssistant, navigations=all и один WSpeed; это явный шаблон редактора, не попытка материализовать все штатные defaults. Widget template сохраняет исходные настройки и границы. Все операции reversible через единую историю. Page identity хранится отдельно от XCFG вместе с widget identity; fallback выделения после undo не оставляет UI на несуществующей странице.

Inspector меняет только затронутые _bg, _border, _theme и для четырёх классов _title, _unit, _hide_labels, titletext. Вариант темы «Из настроек XCTrack» удаляет override. Прочие поля не исправляются и не сериализуются. Свой titletext сохраняется, но на non-PRO native может игнорироваться. Каталог и новые поля сериализуются отдельно, исходные объекты импортированного файла остаются token fragments. Операции над массивами могут изменить разделители/whitespace выбранного массива, сохраняя лексемы всех его исходных объектов и байты вне этого массива.

Ctrl+Z/Ctrl+Y/Ctrl+Shift+Z управляют историей, Ctrl+S скачивает XCFG; внутри input остаются штатные действия текстового поля. На сфокусированном холсте стрелки сдвигают выделение на ячейку; Shift — на десять ячеек, Delete удаляет виджет, Escape отменяет жест.

Добавлены детерминированные учебные сценарии thermal/glide/no-data, запуск/пауза, seek до 3600 s и темп 0.5/1/2/5×. Clock считает elapsed monotonic time, а не кадры; показания вычисляются по позиции сценария. Ручные значения доступны отдельно. Сценарии не реализуют native averaging/flight algorithms и не изменяют Document или экспорт. Карты и сложные виджеты по-прежнему имеют schematic renderer.

Native QA основного редактора: XCTrack 0.9.12.6 принял созданный браузером pages-only export в режиме «Заменить только окна». Штатный backup сохранил все заданные CLASS, counts, order, bounds, page settings и widget fields обеих ориентаций; preferences не изменились. Native добавил default поля (_units, backwardDetection, avg, пустые _theme/titletext). Исходная раскладка эмулятора восстановлена из сохранённого backup-05 через native import. Это runtime compatibility данного контролируемого документа, не доказательство полного visual parity или поддержки произвольного unknown CLASS. См. research/editor-native-roundtrip.json.

Автосохранение локального черновика включено постоянно, переключатель удалён. Оно сохраняет документ после изменения/undo/redo с задержкой 500 мс; ошибки IndexedDB не блокируют экспорт. Восстановление черновика после перезапуска остаётся явным действием. «Экран», «Раскладка страниц», выбор ориентации и страницы перенесены внутрь preview.

Отдельное меню карты удалено из интерфейса. OSM с дорогами подключается для картографических виджетов автоматически, трек, маршрут и точки отображаются при наличии соответствующих данных симуляции. Масштабирование колесом сохранено, drag на холсте управляет виджетами. Параметр routes в XCFG сохраняется, но для preview маршрут теперь включён постоянно по запросу пользователя. Цвет/толщина и остальные native параметры рендеринга остаются из виджета.

В редакторе центр определяется Geolocation API браузера (без high accuracy, с ограниченным ожиданием). Если координаты недоступны, выполняется запрос GeoJS только для геолокации IP: https://www.geojs.io/docs/v1/endpoints/geo/. XCFG и координаты браузера сервису не передаются. При недоступности обоих источников остаётся резервный центр с понятным статусом. GPS симуляции/IGC имеет приоритет над центром редактора. Эти координаты не входят в XCFG. Старые adapters KK7/XContest и MapPanel сохранены в исходниках; ручные источники из удалённого меню больше не выбираются, автоматический подбор наборов воздушных зон этим изменением не добавлен.
Проверки: npm run check — 112 Vitest, 6 Python, TypeScript/ESLint/Prettier/build; полный npm run test:e2e с приватным образцом — 24 passed, 2 optional skipped. Browser Geolocation и IP fallback проверены с контролируемыми координатами/ответами; это не подтверждение реального местоположения компьютера. Проверены GPS follow, возврат из завершённого IGC в редактор, маршрут при routes:false без изменения XCFG, автоматическое сохранение/восстановление и offline failure isolation. Удаление черновика отменяет ожидающий таймер записи, не отключая сохранение следующих изменений.
