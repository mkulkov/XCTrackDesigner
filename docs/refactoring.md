# Рефакторинг и оптимизация, 2026-10-11

Изменения сохраняют формат XCFG, редакторские операции и модель полёта.

- `App.tsx`: поиск карт и построение списка шаблонов мемоизированы по immutable Document. Обновление времени симуляции больше не запускает эти обходы всех страниц. Изменение координат, дублирование и удаление используют общий обработчик команд, истории и ошибок.
- `WidgetPreview.tsx`: два Canvas-контекста измерения текста создаются лениво и переиспользуются. Контексты раздельные для native advances без кернинга и браузерных метрик. Шрифт задаётся при каждом измерении; сброс к стандартному шрифту сохраняет прежнее поведение при некорректном CSS-размере. Формулы метрик и история размеров не изменены.
- `flight-engine.ts`: постоянные составляющие ветра, курса и снижения рассчитываются один раз на кадр и используются для текущей позиции, истории и трека. Межкадрового кеша нет, перемотка и изменение настроек остаются независимыми.

В `flight-engine.test.ts` добавлены две регрессии длительного полёта: точные значения до рефакторинга, переход через 180° долготы, шаг трека, согласованность истории с прямой перемоткой и изменение настроек.

Локальный микробенчмарк Node.js для кадра на 86400-й секунде: 40 прогревочных вызовов, 7 чередующихся серий по 100 вызовов; медиана планирования 3,243 → 2,607 мс, термика 5,807 → 5,546 мс. Это единичный замер вычислений, не FPS браузера. Для 81 комбинации входов полные кадры совпали через `isDeepStrictEqual`. Скрипт и baseline находятся в `.local`; baseline вычислительного модуля восстановлен по прочитанному до изменения исходнику, поскольку файлы проекта пока не отслеживаются Git.

Проверки: `npm run check` прошёл (typecheck, ESLint, Prettier, 114 TypeScript-тестов, 6 Python-тестов, production build). Полный `npm run test:e2e`: 28 passed, 3 skipped — opt-in проверки private sample, title pipeline и visual library. После финального уточнения сброса Canvas-шрифта повторно прошли `npm run check` и 14 браузерных сценариев `npm run test:e2e -- calibration.spec.ts shell.spec.ts`.

Проверки браузера и тесты подтверждают регрессии веб-приложения, а не полное совпадение с Android XCTrack. Native-совместимость и внешние источники данных этим рефакторингом не расширены.
