# Онлайн-источники карты и внешних данных

Проверено 10.10.2026. По запросу пользователя редактор подключает карту, дороги, воздушные зоны и термики онлайн. Офлайн-библиотека Mapsforge и хранение карт стран не нужны для редактора. Копии данных телефона остаются приватными эталонами в `.local`, не входят в приложение. Оригиналы не изменены.

## Что использует XCTrack

| Данные | Источник и формат | Доказательство |
|---|---|---|
| Карта с дорогами | Mapsforge `.map`, рендерер VTM; загрузка Preferences → Maps → Road Maps → Manage Maps | [Официальное описание карт](https://xctrack.org/AboutMaps.html) |
| Каталог дорожных карт | `https://d.xctrack.org/streetmaps.json` | APK 91260: `map/r.java`, `rest/apis/m.java`; не онлайн-тайлы |
| Воздушные зоны | `airspace.xcontest.org`; также локальные OpenAir | [Официальное руководство](https://xctrack.org/Manual.html) |
| Активация зон | Отдельные обновления расписаний и NOTAM, зависят от страны и срока действия | [Руководство AIR3, на которое ссылается XCTrack](https://www.fly-air3.com/en/support/air3-xctrack-manual/xctrack-manual/preferences2/) |
| Термические точки | `https://thermal.kk7.ch/api/hotspots/csv/` + bounding box | APK 91260: `util/d0.java`; это исторические hotspots |
| Рельеф | Отдельный каталог `Map/gec`; на телефоне обнаружены 219 gzip-файлов | Локальное наблюдение MTP; точный формат высот ещё не декодирован |
| Поворотные точки | `Waypoints`, несколько форматов, распознавание по содержимому | [Официальное руководство](https://xctrack.org/Manual.html) |
| Соревновательная задача | XCTSK JSON, QR/Android sharing, отдельный API | [Официальные интерфейсы соревнований](https://xctrack.org/Competition_Interfaces.html) |

Текущий сайт и APK 0.9.12.6 — разные уровни доказательств. URL S3 из `rest/apis/j.java` относится к каталогу парапланов, а не подтверждённому источнику DEM.

## Реализовано в редакторе

- OSM XYZ: `https://tile.openstreetmap.org/{z}/{x}/{y}.png`. Только тайлы текущего видимого региона, стандартный HTTP cache браузера; без prefetch, архивов и service worker. Видимая атрибуция. [Политика OSM](https://operations.osmfoundation.org/policies/tiles/).
- KK7 heatmap: `https://thermal.kk7.ch/tiles/thermals_all_all/{z}/{x}/{-y}.png?src=127.0.0.1`. TMS Y преобразуется из XYZ, native zoom ограничен 12, затем визуальный overzoom. Атрибуция M. von Känel / thermal.kk7.ch, CC BY-NC-SA 4.0. [Инструкции и лицензия](https://thermal.kk7.ch/#dev). Историческая вероятность не означает текущий термик. Коммерческий выпуск потребует отдельного рассмотрения условий.
- XContest: публичные `/api/v6/files` и `/api/v6/data/{oaid}`. Ответ собственного JSON содержит `polygon` в порядке `[lat,lon]`; адаптер меняет порядок и замыкает кольца. [Описание API](https://airspace.xcontest.org/app/apidescription). Каталог наборов доступен в панели, регион выбирается пользователем.
- Дополнительный источник GeoJSON по HTTPS: Polygon/MultiPolygon, включая отверстия. Нужен CORS поставщика. Проверяются координаты и лимиты: 5 MiB, 5000 features, 100000 точек.

XContest не выставляет CORS для browser fetch и требует идентифицирующий User-Agent. `tools/online-airspaces.ts` реализует фиксированные маршруты `/__xcontest/files` и `/__xcontest/data/{id}` в Vite dev/preview. Upstream строго `airspace.xcontest.org`, только GET, без перенаправлений, credentials и произвольного proxy URL. Таймаут 15 секунд, лимит 5 MiB, максимум 20 ответов в RAM, cache 5 минут и ETag. Cross-site Origin отклоняется. Каталог/зоны запрашиваются только кнопками пользователя. В самостоятельном статическом хостинге этот посредник отсутствует.

Контуры всех зон имеют единый условный стиль. Высотные ограничения, категории, NOTAM и расписания пока не рассчитываются. Красный контур не подтверждает активность. Приложение показывает эту границу возможностей. Данные XContest не распространяются в bundle; общая лицензия на их перераспространение не установлена.

Состояние карты и загруженные зоны отделены от Document/history/export. XCFG и настройки пилота не отправляются поставщикам. Тайловый поставщик получает выбранный регион, IP и обычные браузерные заголовки. По умолчанию запросы отключены; пользователь включает онлайн-слои. На диске приложение не создаёт архивов; обычный HTTP cache браузера сохраняется для соблюдения политики поставщика.

## Проверка и ограничения

Реальный локальный relay вернул Kazakhstan / Almaty (`oaid=982`), 197 зон. Произвольный query URL отклонён HTTP 403. В браузере отображены 197 контуров и OSM-подложка. Наличие одного набора не доказывает полное покрытие страны.

KK7: прямой HTTP GET исследовательского агента подтвердил PNG 200 и CORS `*`. В текущем встроенном браузере URL вернули 403/ошибки fetch. Header `x-dev-hint`: `Invalid src-parameter not matching source host or banned. Get in contact`. Корректное включение порта текущего origin также не позволило загрузить тайл. Успешный live thermal renderer в этой среде **не подтверждён**; для рабочего localhost-доступа может потребоваться согласование с поставщиком. Подмена клиента, авторизация и проксирование термиков для обхода отказа не применялись. UI сообщает недоступность, OSM и редактор продолжают работать.

Unit tests проверяют Mercator, wrap, TMS, overzoom, валидацию полигонов и allowlist посредника. E2E использует mock-источники: слой, 502/сетевые ошибки, очистка старых зон и неизменность экспорта. Mock-проверка не является доказательством доступности внешнего сервиса.

Обновление: центр может следовать `Frame.flight.position`; реализованы pan/zoom, north/heading/track rotation, трек и маршрут. XContest lowerLimit/upperLimit `hfeet` переводятся в метры, `htype` учитывается только для AMSL/AGL. Неизвестные ограничения сохраняются видимыми; FL не превращается в AMSL без модели давления. Активации/NOTAM остаются неизвестными. Эта онлайн-подложка не воспроизводит Mapsforge theme, native scale или полётные алгоритмы XCTrack.
