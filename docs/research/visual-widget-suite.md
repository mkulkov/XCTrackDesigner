# Составные экраны для визуальной проверки XCTrack 91260

Создана отдельная тестовая конфигурация из всего каталога: 78 классов на 10 портретных страницах, две колонки и четыре строки (на последней странице шесть элементов). На соседних колонках используются BlackHCTheme и WhiteHCTheme. Карта XC, карта задачи, помощник термика и компас расположены вместе на первой странице. Оригинальные конфигурации пользователя не изменялись.

Генератор: `node tools/create-visual-library.mjs`. Результат и индекс классов сохраняются в `.local/android-qa/visual-library.xcfg` и `visual-library-index.json`. Это страницы без пользовательских preferences. Импортировать в XCTrack через «Загрузить настройки», режим «Заменить только окна». Перед импортом текущая конфигурация эмулятора экспортирована и скопирована в `.local/android-qa/pre-visual-suite-backup.xcfg`.

## Подтверждение на эмуляторе

Эмулятор `emulator-5554`, Android 15, 1080×2400, 420 dpi. XCTrack показал «Настройки успешно загружены». Набор установлен вместо окон эмулятора; остальные настройки сохранены. Сняты десять страниц: `visual-page-01-flight.png`, `visual-page-02.png` … `visual-page-10.png`. Первый `visual-page-01.png` содержит ещё экран настроек и не считается эталоном. Индекс эталонов и SHA-256: `.local/android-qa/visual-native-manifest.json`.

Визуально проверены карта/thermal/компас, текстовые значения и подписи обеих тем, масштабная линейка и доступность отдельных классов. Стационарный эмулятор показывает отсутствие части показаний, ограничения PRO и пустые диагностические виджеты. Это подтверждение импорта и внешнего вида в конкретном состоянии, а не всех режимов всех виджетов.

## Исправления renderer

- `widget/helper/x.b,c,a,e`: указатель ветра расположен на пересечении луча wind-from из точки пилота с рамкой виджета, с отступом `int(2 * metric)`. Наконечник направлен внутрь. Вместо произвольной синей заполненной стрелки используются штатные линии с обводкой и theme.S (80/80/80 на светлой теме, 192/192/192 на тёмной). При нулевой/отсутствующей скорости стрелка скрыта. Подпись скорости учитывает Unit.WindSpeed. Положение подписи ограничено рамкой; native упаковка пересекающихся подписей ещё приближённая.
- `theme/a.Q`: маркер пилота построен с радиусом `2.5 * metric * sizecoef`, задними вершинами ±140°, точками центра и штатной полупрозрачностью. Раньше использовался фиксированный радиус 15px. Общие элементы используются для thermal, карты и онлайн-подложки. Размер экрана передаётся отдельно от размеров виджета.
- `b7/a.e`: указатель севера находится снизу справа, состоит из круга и двух половин стрелки; отображается по rotation.showCompass. Убрана постоянная N-стрелка сверху справа в онлайн-карте.
- `map/n0.a`, `n4/n.a,b`: шаги масштабной линейки 3/4/5/6/8/10/12/15/20/25, длина на основе native zoom и широты, отступы в физических миллиметрах. Линейка стала скобкой с подписью сверху. Тепловая карта при manual zoom использует native Mercator scale; автоматический viewport и остальные модели масштаба остаются независимыми.
- `theme/a`, `WVerticalGraph`, `WVarioColumn`: исправлены цвет и обводка N компаса, целочисленная ширина/центр стрелки графика и границы сегментов вариометра.
- Удалена служебная надпись «Онлайн-карта выключена» из графики карты.

## Воспроизводимая проверка браузера

```powershell
node tools/create-visual-library.mjs
$env:XCT_VISUAL_SUITE='.local/android-qa/visual-library.xcfg'
$env:XCT_QA_SAMPLE='C:\path\to\your\private-sample.xcfg'
npm run check
npm run test:e2e
```

`visual-library.spec.ts` сохраняет отдельные SVG screenshots 1080×2400 в `.local/android-qa/visual-web/`, проверяет количество элементов каждой страницы и точную сохранность байтов XCFG. Показания браузера сейчас берутся из независимой симуляции. Между native и browser не синхронизированы часы, ветер, маршрут, положение и отсутствующие внешние сенсоры. Поэтому процент pixel parity не вычисляется и совпадение всех пикселей не заявляется.

## Оставшиеся границы

Карты поставщиков онлайн имеют другую подложку, чем штатный VTM renderer. Native раскладка навигационных подписей, солнечный указатель, столкновения подписей, автоматический масштаб и выбор тепловых центров ещё не воспроизведены полностью. Платформенные действия, debug/WebView, датчики и лицензионные PRO сообщения отличаются от редактора. Отдельное доведение font raster parity по прежнему запросу пользователя не выполнялось. При ненулевом ветре новая геометрия проверена по исходникам и браузеру; стационарные скриншоты эмулятора не подтверждают airborne wind overlay.
