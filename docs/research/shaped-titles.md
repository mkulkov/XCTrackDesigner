# Сверка с новым снимком эмулятора: заголовки

2026-10-10, XCTrack 0.9.12.6, emulator-5554, 1080×2400, 420 dpi.

Повторно импортирован `tests/fixtures/calibration.xcfg` через native «Заменить только окна». После возврата в flight screen повторный снимок `.local/android-qa/precision-native-restart.png` побайтно совпал с неизменяемым `screenshots/calibration-values-portrait.png`: SHA256 `48db60a6cac070d942502f6d93982d9086bfdd6aea8b23b9ebc45c3dca0e7a4b`. Первый кадр после импорта имел временную другую ширину области; он не использован для подгонки координат. Эталон не масштабировался и не перезаписывался.

В APK `theme/a.java:a0` заголовок рисуется одним `Canvas.drawText` с центрированием. Прежний браузерный renderer задавал X для каждого символа, отключая shaping/kerning строки. Теперь title измеряется цельной строкой Canvas и рисуется одним SVG text с одним X. Числа и единицы сохраняют прежние округлённые advances и историю размера. Поправок ширины под конкретные слова нет.

Результат в [машинном отчёте](shaped-title-comparison.json): 14 266 отличающихся пикселей вместо 15 066 у предыдущего профиля; улучшение 800 пикселей. Это не процент точности виджетов: большая часть экрана пустая. Маска сравнения включает anti-alias, threshold 0.1, без ресайза. Коробка точного цвета заполнения цифры скорости совпадает: [199,163,388,448]. У вариометра остаётся вертикальное отличие до 2 px. Заголовок скорости шире native на 5 px вместо 7, вариометра на 14 вместо 19, времени на 4 вместо 6. AMSL теперь шире на 2 px; это локальная регрессия, поскольку целая строка используется последовательно для всех заголовков. Коробки считаются только по точному RGB, не по всему сглаженному контуру.

Проверен отдельный CanvasKit 0.42.0 эксперимент: CPU Normal 15 139 пикселей, CPU с Paragraph shaping 14 227, GPU 12 481. Однако GPU сдвинул speed mask на 1 px, нарушив строгую проверку геометрии. Slight hinting ухудшил результат до 28 863 и изменил размер вариометра. Эти варианты не включены в приложение. Зависимость CanvasKit и дополнительный маршрут шрифта удалены; экспериментальные копии остались приватно в `.local`. Нельзя объявлять GPU результат точным соответствием Android.

После исследования native успешно загрузил приватный backup с выбором «Заменить только окна»; остальные настройки сохраняются по native опции. Это UI подтверждение восстановления, новый полный export после восстановления в этом проходе не сравнивался. Оригинальный пользовательский XCFG и APK сохранили прежние SHA256. Private fonts и backups не публикуются.

Полное соответствие ещё не достигнуто. Следующая работа: установить причину отличий DEFAULT_BOLD/Roboto glyph advances и сглаживания Android HWUI, затем проверить дополнительные controlled размеры, unit-off и отрицательные значения. Нельзя исправлять их произвольным сжатием отдельных подписей или наложением screenshot вместо renderer.

Проверки приложения: typecheck, ESLint, Prettier, 26 Vitest, 6 Python и 5 Playwright E2E с исходным private sample. E2E проверяет единый X заголовка, строгую коробку speed, допуск vario, слои/альфу, историю 0→300→0, reset и byte-preserving export. История остаётся APK-derived/browser-verified; эта последовательность не воспроизведена native с управляемыми полётными данными.
