# Локальный запуск и восстановление

## Отдельное окно Windows

`release/XCTrack-Screen-Designer-0.1.0-win-x64.exe` — переносимое приложение для Windows 10/11 x64. Двойной щелчок открывает редактор в отдельном окне; Node.js, браузер и установка зависимостей пользователю не нужны. EXE можно скопировать в другую папку. При запуске Electron временно распаковывает встроенные компоненты; профиль и черновики сохраняются отдельно в пользовательском каталоге приложения, доступном через Electron `app.getPath('userData')`.

Экспорт открывает системный диалог сохранения XCFG. Импорт использует выбор файла или перетаскивание. Черновики и тема приложения сохраняются между перезапусками; браузерные черновики с портов 5173/4173 не переносятся автоматически, для переноса экспортируйте XCFG. Окно обслуживается только локальным сервером на `127.0.0.1:4183`; закрытие окна завершает приложение и сервер. Повторный запуск переключает фокус на существующее окно. Если порт занят другой программой, приложение сообщает ошибку.

Сборка из исходников (Node.js нужен только разработчику):

```powershell
npm ci
npm run desktop:pack
```

`npm run desktop` пересобирает и открывает окно через Electron; `npm run desktop:test` проверяет импорт/экспорт, восстановление черновика после перезапуска и закрытие сервера в отдельном временном профиле. Проверка упакованного приложения: `npm run desktop:test -- "release/win-unpacked/XCTrack Screen Designer.exe"`.

В упаковку входят только web build, desktop launcher, runtime и необходимые npm-модули. APK, vendor checkout, личные XCFG, `.local/fonts` и native screenshots не включаются. Используются браузерные замены шрифтов. Онлайн-карты и ограниченный XContest relay поддерживаются; прежнее ограничение KK7 сохраняется. EXE не подписан сертификатом издателя; проверка на другом компьютере и подпись — отдельные шаги.

Упаковка: [electron-builder portable](https://www.electron.build/docs/win/). Изоляция окна: [Electron security](https://www.electronjs.org/docs/latest/tutorial/security/).

## Запуск в браузере

Требования: Windows, Node.js 24.15–24.x, npm. После получения исходников выполните `npm ci`; для разработки — `npm run dev`. Установка Chromium нужна только для автоматических браузерных тестов: `npx playwright install chromium`.

Для обычного использования запустите `Start-Designer.cmd` либо `npm start`. Если сборки ещё нет, launcher создаёт её и запускает сервер только на `127.0.0.1:4173`. Откройте указанный адрес в браузере. Консоль остаётся открытой; Ctrl+C останавливает сервер. После обновления исходников выполните `Start-Designer.cmd -Rebuild`. Другой порт: `Start-Designer.cmd -Port 4175`.

Этот режим обслуживает production build, локальные шрифты при их наличии и ограниченный XContest relay. Шрифты, APK, личные XCFG и карты в распространяемую сборку не включены. Без локальных шрифтов используются браузерные замены. Открытие `dist/index.html` через file:// не заменяет локальный сервер.

Черновик хранится в IndexedDB текущего браузера и origin. Сохранение по кнопке доступно сразу; автосохранение включается отдельно. Восстановление явное и начинает новую историю из сохранённого XCFG. Хранятся исходные байты текущего документа, имя файла и дата, без симуляции и данных карты. Ошибки/запрет IndexedDB не блокируют редактирование и экспорт. Очистка данных браузера удаляет черновик. Для переноса и резервной копии используйте экспорт XCFG; черновик не заменяет файл. Черновики портов 5173 и 4173 независимы.

Редактор и экспорт работают без внешней сети. Онлайн-подложка, зоны и термики требуют подключения; ошибки источников отображаются отдельно. Браузер может кэшировать обычные HTTP-ответы, но приложение не скачивает офлайн-архивы. KK7 сейчас отклоняет localhost-запросы: нужен разрешённый источник или согласование поставщика, обход ограничения не реализован.

Совместимость: профиль 0.9.12.6 / 91260 поддерживает редактирование. Другие версии можно открыть для просмотра и сохранения исходного документа; их редактирование требует отдельного исследования. Диагностические классы каталога могут быть исключены штатным XCTrack в обычном режиме; PRO-функции зависят от XCTrack entitlement. Imported WebView и Android-действия не исполняются браузером.

Проверки перед использованием новой сборки: `npm run check`, затем `npm run test:e2e`. Native import/export проверяйте в эмуляторе с резервной копией. Установщик и облачное размещение в эту локальную поставку не входят; отдельное окно поставляется переносимым EXE.
