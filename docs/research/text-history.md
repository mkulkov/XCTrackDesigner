# История размеров текста

Продолжение калибровки 2026-10-10, профиль 91260. Перенесены исторические ограничения размера из `theme.a.U` и `sm.a`: максимальные нормализованные ширина/высота, измерение на предыдущем размере Paint и округление нового размера. Для числа и единиц сохраняются независимые максимумы; размер Paint передаётся между их последовательными вызовами. Двухстрочная единица рассчитывается единым блоком по самой широкой строке и суммарной высоте.

В preview история сохраняется при изменении показаний и переключении рамок. Missing input не обнуляет историю. При импорте, переходе на другую страницу, изменении координат/настроек или шрифта история начинается заново. Кнопка «Сбросить размеры текста» явно начинает новый расчёт. Это состояние renderer, оно не попадает в XCFG или undo/redo документа. Рендер повторного React frame не меняет кеш: обновление выполняется один раз на новую комбинацию показаний, с копией предыдущего состояния.

Проверены чистыми тестами: короткое → длинное → короткое без обратного увеличения; выравнивание после уменьшения; независимость числа и единиц; сохранение при null; стабильность двухстрочного блока. E2E выполняет 0 → 300 → 0, переключение рамок, сброс и byte-identical экспорт. Результат последовательности сохраняется в `.local/text-history.json`.

Это APK-derived модель, проверенная в браузере. Динамическая последовательность на настоящем XCTrack с теми же управляемыми входами пока не получена. Сохранение кеша между скрытыми native страницами и все native invalidation paths не подтверждены; описанная политика reset относится к веб-прототипу.

## Заголовки и контроль регрессии

Новый [контрольный отчёт](history-calibration-comparison.json) включает bounding boxes пикселей title color #7f7f7f. Без изменения первого stationary кадра осталось 15066 отличающихся пикселей / 0.58125%. Speed ink-box по цвету заполнения совпадает; vario сохраняет прежний допуск 2 px по вертикали. AMSL title box совпадает. Speed title шире на 7 px, vario title на 19 px, time title на 6 px, согласно коробкам точного цвета, без anti-alias краёв. Это точные измерения данного reference, не поправочные коэффициенты для любых слов.

Проверен альтернативный `RobotoStatic-Regular.ttf` из того же emulator с browser synthetic bold: 15078 px, ухудшение на 12 px. Он не принят как замена; [отчёт эксперимента](title-variant-comparison.json) сохранён отдельно. Исходный Roboto-Regular и custom XCTrack font остаются рабочим профилем. Для полного совпадения заголовков ещё нужны native glyph advances/hinting/default typeface measurements; произвольное сжатие строк под один screenshot не добавлено.

Проверки: `npm run check` (typecheck, ESLint, Prettier, 26 Vitest, 6 Python, build), 5 E2E с исходным private sample. Оригиналы не изменялись; fonts и полные backups остаются `.local`.
