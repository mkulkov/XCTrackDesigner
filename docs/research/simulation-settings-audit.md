# Параметры виджетов при симуляции

Проверка 2026-10-10: каталог из 78 классов, общий путь WidgetPreview, value-layout/widget-content, NativeFlightGraphics, NativeStatusButtons, GraphicWidget и OnlineMap. Это проверка исходного кода и браузерных сценариев, не доказательство native parity всех параметров.

## Передача конфигурации

App передаёт копию выбранного виджета с черновиком инспектора. WidgetPreview добавляет отсутствующие defaults каталога, затем перекрывает их данными виджета. Общие preferences передаются отдельно; пустой `_theme` использует Display.Theme. Ключ компонента содержит виджет, черновик, preferences и размеры, поэтому изменение оформления обновляет числовые и графические preview. Симуляция подменяет показания, но не настройки XCFG.

## Исправленные расхождения

- OnlineMap использовал жёсткие синий цвет и толщину трека. Теперь использует `tracklog_color` с alpha ARGB и `line_thickness`; тот же стиль применяется к обычному графическому preview карт. Цветные сегменты WThermalAssistant/WVTM сохранены: это вариометрическая раскраска, а не цвет обычного трека.
- Начальный поворот онлайн-карты следует `rotation` виджета. Ручной выбор в меню карты явно переопределяет его. Поддержаны север, курс, направление трека, ветер и направление следующей точки.
- `mapWidget_showAirspaces` скрывает зоны, `mapWidget_showKK7` скрывает слой KK7, `mapWidget_KK7opacity` задаёт его opacity. Меню карты подключает источник, параметры конкретного виджета управляют его отображением.
- `mapWidget_drawBearing` управляет линией направления полёта; `nav_line` при доступной задаче и выбранной цели управляет отдельной навигационной линией. `routes` управляет маршрутом и его точками. Стрелка ветра и размер маркера пилота уже используют настройки виджета.
- ARGB, включая полностью прозрачный цвет, сохраняется. Черновик цвета/толщины отображается до применения, экспорт исходной конфигурации остаётся прежним.

## Остальные выявленные ограничения

Общая передача параметров исправна, но это не означает реализацию каждой native опции. Остаются конкретные пробелы:

| Параметры | Текущее ограничение |
|---|---|
| WVerticalSpeed.avg, WGlide.avg, WNettoVario.netto_avg | Подпись учитывает интервал; числовое показание пока не реализует соответствующее усреднение |
| WNextTurnpointAlt.altitude | Подпись режима меняется; модель ещё не разделяет все AMSL/AGL/DROP расчёты |
| WNextTurnpointGlideTo.alt_above | Модель не учитывает запас высоты этого виджета |
| mapWidget_scale/mapScale | Обычная графика поддерживает относительный/native thermal масштаб; онлайн-карта использует масштаб меню, native auto-scale не перенесён |
| mapWidget_pilotPosCenter/mapWidget_pilotEdgeDistance | Онлайн-карта при GPS-follow пока располагает пилота в центре |
| WLiveMessage.show_time | Ручные сообщения — строки без структурированной истории времени |
| nav_use_brackets/nav_showSun | Native размещение скобок и указателя солнца не реализовано |
| mapAppearance, rain radar, live pilots, obstacles, waypoints/cities/takeoffs | Нет соответствующих источников или native painter; OSM имеет стиль поставщика |

IAS/TAS, полярные/netto вычисления, ESS, оптимизация XContest, thermal detection и действия Android остаются за пределами текущей учебной модели. Они не объявляются реализованными на основании сохранения параметра в XCFG. Полное покрытие путей отрисовки: [widget-rendering-coverage.md](widget-rendering-coverage.md).
